# MNIST Klassifikation: NN vs. DNN Vergleich

Dieses Projekt wurde im Rahmen einer **Projektarbeit für Machine Learning (2026)** entwickelt. Es vergleicht die Leistung eines flachen neuronalen Netzes (**NN**) mit einem tiefen neuronalen Netzes (**DNN**) bei der Klassifikation handgeschriebener Ziffern.

## Features
- **Interaktives Dashboard**: Schritt-für-Schritt-Führung durch den ML-Prozess mit Streamlit.
- **Modell-Vergleich**: Analyse von Architekturunterschieden (Shallow vs. Deep).
- **Live-Training**: Überwachung von Accuracy und Loss während der Epochen.
- **PPTX-Export**: Automatisierte Erstellung einer Präsentation der Ergebnisse.
